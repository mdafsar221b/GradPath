# GradPath Advanced BCA Upgrade Plan

This document tracks the one-go upgrade from a basic semester tracker into a focused BCA student platform.

## Phase 1 - Foundation

- Stabilize lint/build workflow.
- Fix default metadata and app identity.
- Reduce loose frontend typing.
- Improve resource filtering and API consistency.
- Add safer admin/resource foundations.

## Phase 2 - BCA Study Intelligence

- Add a smart study API that derives daily priorities from assignments, progress, subjects, units, and resource coverage.
- Add exam-prep insights from PYQ coverage.
- Surface weak subjects, incomplete units, and recommended next actions.

## Phase 3 - Student Experience

- Upgrade the dashboard from a passive summary into a daily command center.
- Add subject/resource recommendations.
- Add exam-focused PYQ and revision signals.
- Make resources searchable by subject, type, difficulty, year, and category.

## Phase 4 - Admin Experience

- Expand resource metadata: tags, difficulty, year, exam session, description, source, and estimated study time.
- Improve admin analytics beyond raw resource counts.
- Prepare content workflows for review, publishing, and quality scoring.

## Phase 5 - Next Advanced Milestones

- Topic-level confidence tracking inside subject units.
- AI-generated quizzes, quiz attempts, flashcards, and spaced repetition reviews.
- Coding lab for C, C++, Java, SQL, DSA, and Web Development with AI review.
- Final-year project workspace.
- AI tutor grounded in subject, unit, topics, and uploaded resources.
- Attendance, internals, exam calendar, and career roadmap.
